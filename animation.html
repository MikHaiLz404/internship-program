Animator Intern

Bring Games to Life Through Animation

ข้อมูลทั่วไป

  • จำนวนรับ: 2 ตำแหน่ง
  • ระยะเวลา: 4-6 เดือน (ยืดหยุ่นตามภาคเรียน)
  • สถานที่: Hybrid Work (สลับทำงานที่สำนักงานและที่บ้าน)
  • เวลาทำงาน: จันทร์-ศุกร์ 09:00-18:00 น.
  • โปรเจคปัจจุบัน: Regulus - The Advent, Father's Son and Holy Gun

เกี่ยวกับตำแหน่ง

Animation Department ของเราทำให้เกมมีชีวิตชีวาด้วยการสร้างองค์ประกอบที่เคลื่อนไหวทั้งหมดที่คุณเห็นและโต้ตอบในระหว่างการเล่นเกม เราทำงานทุกอย่างตั้งแต่ character animations และ creature movements ไปจนถึง UI transitions, in-game cinematics และ interactive game assets

โปรแกรม internship ของเราออกแบบมาเพื่อพัฒนาทักษะ animation ของคุณผ่านการฝึกอบรมและการให้คำปรึกษาแบบ hands-on ช่วยให้คุณสร้างรากฐานที่จำเป็นในการเป็น animator ที่มีทักษะ เรายินดีต้อนรับ interns ที่มีความกระตือรือร้นที่ต้องการพัฒนาฝีมือในสภาพแวดล้อมการเรียนรู้ที่ร่วมมือและสนับสนุน

คุณสมบัติ

  • มีความเข้าใจพื้นฐานเกี่ยวกับหลักการ animation
  • มีทักษะการสังเกตที่ดีและความใส่ใจในรายละเอียด
  • มีความสามารถในการสื่อสารที่มีประสิทธิภาพกับสมาชิกในทีม
  • มีแนวทางเชิงรุกในการถามคำถามและแสวงหาคำชี้แจง
  • มีความกระตือรือร้นและความสามารถในการปรับตัวเพื่อเรียนรู้เทคนิคและ workflows ใหม่ๆ
  • มีแนวคิดในการแก้ปัญหาอย่างสร้างสรรค์

ความรับผิดชอบหลัก

  • สร้าง animations สำหรับ characters, creatures, objects และ game elements ต่างๆ ตามงานที่ได้รับมอบหมายและคำแนะนำจาก mentors สำหรับแต่ละ practice task
  • ทำงานร่วมกับทีมข้ามสายงานอย่างใกล้ชิดและให้การสนับสนบในการแก้ปัญหาเมื่อมีปัญหาทางเทคนิคเกิดขึ้นในระหว่างการผลิต
  • เรารักษากระบวนการควบคุมคุณภาพอย่างเข้มงวด ตรวจสอบทุกชิ้นงานอย่างละเอียดก่อนส่งมอบเพื่อให้มั่นใจในการส่งมอบที่ราบรื่นไปยังทีมอื่น
  • กิจกรรมประจำวัน: รวบรวมเอกสารอ้างอิง, การหารือและวางแผนของทีม, hands-on animation work, รวมข้อเสนอแนะผ่านการแก้ไขซ้ำๆ จนได้รับการอนุมัติ และนำ animations ไปใช้ใน game เพื่อการทดสอบและตรวจสอบ

สิ่งที่จะได้เรียนรู้

  • พัฒนาทักษะ animation พื้นฐานที่สามารถนำไปใช้ได้อย่างมีประสิทธิภาพในสภาพแวดล้อมการผลิตแบบมืออาชีพ
  • เรียนรู้กระบวนการทดสอบเกมในสภาพแวดล้อมการพัฒนาแบบมืออาชีพ
  • ระบุ วิเคราะห์ และรายงานข้อบกพร่อง
  • เข้าใจประเภทของการทดสอบ (functional, compatibility, regression, performance) และวิธีเลือกการทดสอบที่เหมาะสม
  • เรียนรู้การใช้เครื่องมือติดตามบั๊กและเอกสารการทดสอบ (test cases, test plans)

Reference: Video capture tools, Reference libraries

Collaboration: Perforce, Git, Google Drive

Communication: Slack, Discord, Zoom
