เกี่ยวกับตำแหน่ง

The main responsibilities of a game designer are to create a "FUN" factor for the game. The team environment is open-minded and encourages discussion about design factors.

คุณสมบัติ

  • Design Principles: Familiarity with concepts like flow, pacing, feedback loops, player motivation, and balancing.
  • Documentation Tools: e.g., Google Docs, Microsoft Office Suite, Miro, Confluence.
  • Verbal: Clearly articulating ideas, designs, and feedback in team discussions.
  • Written: Producing clear, concise, and comprehensive design documents.
  • Love Playing Games
  • Preferred: Game Engine: Unity/Unreal

ความรับผิดชอบหลัก

  • Assisting with Game Features: Helping to design and balance game features, systems, mechanics, and content.
  • Documentation: Creating and maintaining detailed design documents, game flows, system designs.
  • Level Design: Contributing to the design and implementation of levels, environments, stories, and quests (If apply for Level Designer).

สิ่งที่จะได้เรียนรู้

  • Documentation Best Practices: Learn to create professional-grade design documents (GDDs).
  • Version Control Systems: Understand and use tools like Git.
  • Receiving and Giving Feedback: Develop the crucial skill of receiving constructive criticism.
  • Building a Portfolio: Acquire tangible work experience.
  • Networking: Establish connections with industry professionals.

Software และ Tools ที่ใช้

Software: Google suite, Microsoft Office, Adobe program, Autodesk program, Blender, Unity, Unreal engine
