Software Developer (Web & Backend)

Web Application & Backend Services Internship

ข้อมูลทั่วไป

  • จำนวนรับ: 2 ตำแหน่ง
  • ระยะเวลา: 4-6 เดือน (ยืดหยุ่นตามภาคเรียน)
  • สถานที่: Hybrid Work (สลับทำงานที่สำนักงานและที่บ้าน)
  • เวลาทำงาน: จันทร์-ศุกร์ 09:00-18:00 น.
  • ค่าตอบแทน: สอบถามเพิ่มเติม

คุณสมบัติ

  • กำลังศึกษาในระดับปริญญาตรี สาขา Computer Science, Software Engineering หรือสาขาที่เกี่ยวข้อง
  • มีความรู้พื้นฐานด้าน Web Technologies: HTML, CSS, JavaScript
  • มีความคุ้นเคยกับ Frontend Framework (Angular, React, Vue) เป็นข้อได้เปรียบ
  • มีความรู้พื้นฐานด้าน Backend Programming: C# หรือ Node.js
  • เข้าใจพื้นฐาน Database (SQL Server และ/หรือ MongoDB)
  • มีความรู้เกี่ยวกับ Version Control (Git)
  • กระตือรือร้นที่จะเรียนรู้เกี่ยวกับ Containerization (Docker) และ CI/CD (Jenkins)
  • มี Problem-solving skills ดี และเต็มใจทำงานในสภาพแวดล้อมแบบ Agile
  • มีทักษะการสื่อสารที่ดี และมีทัศนคติเชิงรุก
  • ต้องส่ง Code Repository (GitHub/GitLab/Bitbucket) ตัวอย่างโปรเจค

ลักษณะงาน

  • พัฒนา Web Applications ที่ตอบสนองบนอุปกรณ์ต่างๆ โดยใช้ Angular เพื่อประสบการณ์ผู้ใช้ที่ราบรื่น
  • ออกแบบ สร้าง และดูแล RESTful APIs และ Backend Services โดยใช้ Node.js และ C# (.NET Core)
  • รวมและจัดการข้อมูลใน relational (SQL Server) และ NoSQL (MongoDB) databases รวมถึงการปรับแต่งประสิทธิภาพและการออกแบบ schema
  • ใช้งาน containerized applications ด้วย Docker เพื่อการพัฒนา ทดสอบ และ deploy ที่สอดคล้องกัน
  • ทำงานร่วมกับ CI/CD pipeline development และ automation โดยใช้ Jenkins เพื่อการ deploy ที่รวดเร็วและเชื่อถือได้
  • เขียน code ที่สะอาด ดูแลรักษาได้ และมีเอกสาร ตามแนวปฏิบัติของอุตสาหกรรมและมาตรฐานการเขียน code ภายใน
  • ทำ Code Reviews และเข้าร่วมกระบวนการพัฒนาแบบ Agile รวมถึง Sprint Planning, Daily Stand-ups และ Retrospectives
  • Troubleshoot, Debug และปรับปรุง Web Applications และ APIs เพื่อประสิทธิภาพและความเชื่อถือได้สูงสุด
  • ทำงานร่วมกับ Designers, QA, DevOps และ Engineers อื่นๆ เพื่อส่งมอบ Software Solutions คุณภาพสูงตรงเวลา

สิ่งที่จะได้รับ

  • ประสบการณ์ hands-on จากการทำงานกับ real-world product ในบริษัทเกม
  • เรียนรู้แนวปฏิบัติที่ดีที่สุดในการเขียน code ที่สะอาด ดูแลรักษาได้ ใน Unity และ C#
  • ได้รับประสบการณ์การทำงานในสภาพแวดล้อมการพัฒนาแบบมืออาชีพ
  • พัฒนาทักษะ Problem-solving และ Collaboration ด้วยการทำงานร่วมกับ Developers ที่มีประสบการณ์
  • ได้รับคำแนะนำจาก Senior Team Members และความรู้ที่มีค่าเกี่ยวกับอุตสาหกรรมเกม
  • สภาพแวดล้อมการทำงานที่เป็นมิตรและมุ่งเน้นเป้าหมาย ที่ Interns ได้รับการปฏิบัติเป็นสมาชิกที่มีค่าของทีม
  • โอกาสในการได้รับการพิจารณาเป็นพนักงานประจำหลังจบ Internship

เทคโนโลยีที่ใช้

Frontend: Angular, HTML, CSS, JavaScript, TypeScript

Backend: Node.js, C# (.NET Core)

Database: SQL Server, MongoDB

DevOps: Docker, Jenkins, CI/CD Pipelines

Version Control: Git (GitHub, GitLab, Bitbucket)

Tools: Postman, Visual Studio Code, GitHub

Methodology: Agile/Scrum
