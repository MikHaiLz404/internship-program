Web Application & Backend Services Internship

General Information

  • Positions: 3 positions
  • Duration: Flexible
  • Location: Hybrid Work

About the Role

The Software Engineering & Web Services Department plays a critical role in building the digital backbone of our game development company. We build responsive, interactive web apps using Angular, and develop scalable backend systems using Node.js and C# (.NET Core).

Work Environment

We offer a collaborative and goal-oriented environment where innovation is encouraged. You will work alongside experienced developers who are passionate about sharing their knowledge. We follow agile methodologies to ensure efficient delivery and continuous improvement.

Qualifications

  • Currently pursuing or recently completed a degree in Computer Science, Software Engineering, or related field.
  • Basic understanding of web technologies such as HTML, CSS, and JavaScript.
  • Familiarity with Angular or any frontend framework (e.g., React, Vue) is a plus.
  • Exposure to or basic knowledge of backend programming languages like C# or Node.js.
  • Understanding of databases – relational (SQL) and/or NoSQL (MongoDB).
  • Awareness of version control systems like Git.
  • Eagerness to learn about containerization (Docker) and CI/CD pipelines (Jenkins).

Key Responsibilities

  • Develop and maintain responsive web applications using Angular.
  • Design, build, and maintain RESTful APIs and backend services using Node.js and C# (.NET Core).
  • Integrate and manage data across both relational (SQL Server) and NoSQL (MongoDB) databases.
  • Implement and manage containerized applications using Docker.
  • Collaborate in CI/CD pipeline development and automation using Jenkins.

Learning Objectives

  • Building and deploying real-world applications using Angular, Node.js, and C#.
  • Working with both SQL and NoSQL databases in real-world scenarios.
  • How DevOps tools like Docker and Jenkins fit into modern software development workflows.
  • Best practices for writing clean, testable, and maintainable code.

Tools & Technologies

Frontend: Angular, HTML, CSS, JavaScript

Backend: Node.js, C# (.NET Core)

Database: SQL Server, MongoDB

DevOps: Docker, Jenkins

Tools: Visual Studio, Visual Studio Code, Postman, GitHub
