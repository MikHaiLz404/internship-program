Game Developer (Unity)

Frontend Developer & Unity Developer Internship

ข้อมูลทั่วไป

  • จำนวนรับ: More than 3 ตำแหน่ง
  • ระยะเวลา: Flexible (ยืดหยุ่นตามภาคเรียน)
  • สถานที่: Hybrid Work (สลับทำงานที่สำนักงานและที่บ้าน)
  • เวลาทำงาน: จันทร์-ศุกร์ 09:00-18:00 น.

เกี่ยวกับตำแหน่ง

Our team plays a crucial role in the game development lifecycle, from designing game architecture and implementing features to supporting other teams to ensure the highest quality game experience. We work primarily on the game client, using the Unity Engine.

คุณสมบัติ

  • An interest in game development or previous experience in a related capacity.
  • A basic understanding of the Unity Engine and C#.
  • Familiarity with Git and version control concepts.
  • Good problem-solving skills and a proactive attitude.
  • Good communication skills and a willingness to share ideas with the team.
  • Willingness to learn and collaborate with others in an agile environment.

ความรับผิดชอบหลัก

  • Design and develop engaging gameplay systems based on project and team needs.
  • Work with the Unity Engine and C# to write clean, maintainable, and well-documented code.
  • Actively participate in our agile development processes, including sprint planning, daily stand-ups, and retrospectives.
  • Collaborate closely with team members and other departments in an agile environment.

สิ่งที่จะได้เรียนรู้

  • Gain an understanding of the game development pipeline by working on a real-world product.
  • Learn industry best practices for writing clean, maintainable code in Unity and C#.
  • Get hands-on experience working in a professional development environment.
  • Improve problem-solving and collaboration skills by working alongside experienced developers.
  • Receive mentorship from senior team members.

Software และ Tools ที่ใช้

Software: Unity, Visual Studio, VS Code, Git

Languages: C#
