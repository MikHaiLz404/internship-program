Technical Artist Intern

Bridge the Gap Between Art and Code

ข้อมูลทั่วไป

  • จำนวนรับ: 1 ตำแหน่ง
  • ระยะเวลา: 4 เดือน (ยืดหยุ่นตามภาคเรียน)
  • สถานที่: Hybrid Work (สลับทำงานที่สำนักงานและที่บ้าน)
  • เวลาทำงาน: จันทร์-ศุกร์ 09:00-18:00 น.
  • โปรเจคปัจจุบัน: Regulus: The Advent, Father, Son, Holy Guns

เกี่ยวกับตำแหน่ง

Create game prefabs such as characters and environments. Set up UI Canvas based on Figma designs and optimize for different platforms. Communicate and coordinate with other teams to improve the quality of the work. Set up Animation Trees so characters can move properly. Create shaders that match the concept art. Write C# scripts to automate repetitive tasks.

คุณสมบัติ

  • Must have: Unity
  • Nice to have: C#, PSD, AE, Adobe Designer
  • Have used Unity for at least 1 year (Preferred)
  • Target Degrees: Computer Science, Computer Engineering, Animation and Multimedia, Information Technology, Interactive Media Games

ความรับผิดชอบหลัก

  • Test skills to see which type of work fits best
  • Practice and improve skills to be ready for joining main projects
  • Take part in main projects within the company

สิ่งที่จะได้เรียนรู้

  • Gained real experience in the game development process
  • Learned techniques and methods for making games

Software และ Tools ที่ใช้

Software: Google suite, Microsoft Office, Adobe program, Autodesk program, Blender, Unity, Unreal engine
