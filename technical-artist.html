เกี่ยวกับตำแหน่ง About the Role

เชื่อมช่องว่างระหว่างศิลปะและการเขียนโปรแกรม สร้างเครื่องมือและ Shaders เพื่อช่วยให้ศิลปินทำงานได้ง่ายขึ้นและเกมมีประสิทธิภาพดีขึ้น Bridge the gap between art and programming. Create tools and shaders to help artists work more efficiently and improve game performance.

บรรยากาศการทำงาน Work Environment

บรรยากาศในทีมเปิดกว้างและส่งเสริมการพูดคุยเกี่ยวกับปัจจัยด้านการออกแบบ กิจกรรมประจำวันคือการค้นคว้าและสร้าง GDD (Game Design Document) The team environment is open-minded and encourages discussion about design factors. Typical daily activities are researching and creating a GDD (Game Design Document).

คุณสมบัติ Qualifications

  • มีความรู้ทั้งด้านศิลปะและการเขียนโปรแกรม Knowledge of both art and programming
  • เข้าใจเรื่อง Rendering Pipeline และ Shaders Understanding of Rendering Pipeline and Shaders
  • สามารถเขียน Script เพื่อสร้างเครื่องมือใน Maya/Blender หรือ Unity/Unreal Ability to write scripts to create tools in Maya/Blender or Unity/Unreal
  • ทักษะการแก้ปัญหาที่ดีเยี่ยม Excellent problem-solving skills

ความรับผิดชอบหลัก Key Responsibilities

  • สร้าง Shaders และ VFX สำหรับเกม Create Shaders and VFX for games
  • พัฒนาเครื่องมือเพื่อเพิ่มประสิทธิภาพ Workflow ของทีมศิลป์ Develop tools to optimize the Art team's workflow
  • ตรวจสอบและปรับปรุงประสิทธิภาพของ Assets ในเกม Profile and optimize game assets for performance

สิ่งที่จะได้เรียนรู้ Learning Objectives

  • การแก้ปัญหาทางเทคนิคในโปรดักชั่นจริง Solving technical problems in real production
  • การเขียน Shader ขั้นสูงและการทำ Optimization Advanced Shader writing and Optimization
  • การสร้าง Pipeline เครื่องมือสำหรับทีมขนาดใหญ่ Building tool pipelines for large teams
