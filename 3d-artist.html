3D Artist Intern

Create Stunning 3D Assets for Games

ข้อมูลทั่วไป

  • จำนวนรับ: 1 ตำแหน่ง
  • ระยะเวลา: 4-6 เดือน (ยืดหยุ่นตามภาคเรียน)
  • สถานที่: Hybrid Work (สลับทำงานที่สำนักงานและที่บ้าน)
  • เวลาทำงาน: จันทร์-ศุกร์ 09:00-18:00 น.
  • โปรเจคปัจจุบัน: Regulus - The Advent, Father's Son and Holy Gun

เกี่ยวกับตำแหน่ง

3D Artist จะได้รับการฝึกอบรมและระบบการให้คำปรึกษา วิชาชั้นเรียนในเกม เช่น ตัวละครจากงานร่วมกัน ด้านเทคนิคหรือนักออกแบบสร้างสรรค์ และผู้กำกับศิลป์ หรือแม้แต่คนอื่นๆที่เกี่ยวข้องกับเทคนิคศิลปะตั้งแต่ concept art ที่ออกแบบมาเป็น visual จำลองภายในเกม

คุณสมบัติ

  • มีความรู้และเข้าใจเกี่ยวกับการทำ model และ texture
  • ทำงานจาก model จาก concept แก้ของ project ที่ผ่านมา
  • ลงมือทำงานจริง ทำ model และ texture จาก concept ข้างบนบนนี้ เจาะลงมาจนเป็นงาน
  • ลงมือทำงานจริง ทำ model และ texture จาก concept ข้างต้นมาจนเติมงาน

ความรับผิดชอบหลัก

  • สร้าง 3D character model และ texture
  • สร้าง 3D environment model และ texture
  • ทำงานร่วมกับทีมเพื่อให้แน่ใจว่างานมีคุณภาพและตรงตามกำหนดเวลา
  • ปรับแต่งและแก้ไข models ตาม feedback จากทีม
  • เรียนรู้และใช้เทคนิคใหม่ๆ ในการสร้าง 3D assets

สิ่งที่จะได้เรียนรู้

  • เรียนรู้และรับทักษะการใช้โปรแกรมและระบบการทำงาน
  • ได้เรียนรู้มือสร้าง model จาก concept ซึ่งสามารถทำงานในกรณีอื่นได้ดีขึ้น
  • ได้ลงมือทำงานจริง จากไป project ใช้จริง และเอาไปลง end credit ของเกมสินค้าในความพยายาม
  • เมื่อโจทีฏภาษาได้ทำงานจริงจากไป project ใช้จริงไปและไม่ได้วัตถุประสงค์ในต่อนั้นมีนะเป็นภาพมีเป็นผลลัพท์นั้นถึงแม้นี้ส่วนคนอื่นเป็นแนวความคิดในหรือ usability flows หรือสิ่งที่ส่งไปโจนเป็น wireframes หรือ game assets อย่างไรก็ตาม คุณภาพของงานต้องเป็นไปตามมาตรฐานอุตสาหกรรมเป็นอย่างน้อย

Software และ Tools ที่ใช้

3D Software: Blender, Maya, 3ds Max, ZBrush

Texturing: Substance Painter, Substance Designer, Photoshop

Game Engine: Unity, Unreal Engine

Version Control: Git, Perforce

Collaboration: Google Drive, Slack

Required Skills

ทักษะการออกแบบ: เข้าใจองค์ประกอบพื้นฐาน เช่น anatomy, perspective, gesture, color, rhythm, composition, shape, material
