Game Designer

Create the "FUN" Factor for Games

ข้อมูลทั่วไป

  • จำนวนรับ: 2 ตำแหน่ง
  • ระยะเวลา: 4-6 เดือน (ยืดหยุ่นตามภาคเรียน)
  • สถานที่: Hybrid Work (สลับทำงานที่สำนักงานและที่บ้าน)
  • เวลาทำงาน: จันทร์-ศุกร์ 09:00-18:00 น.

เกี่ยวกับตำแหน่ง

Game Designer มีหน้าที่หลักในการสร้าง "FUN" factor ให้กับเกม โดยทำงานในทีม Design ซึ่งประกอบด้วย Game Designers และ UX/UI Designers

โปรเจคที่กำลังพัฒนาในแผนก Game Design:

  • Live Service RPG Gacha Base
  • Rougelite Co-op
  • Souls Like

คุณสมบัติ

  • มีความรู้พื้นฐานเกี่ยวกับ Game Design หรือ Game Development
  • มีทักษะการสื่อสารและการทำงานเป็นทีมที่ดี
  • อ่านและเขียนภาษาอังกฤษในระดับที่จำเป็นสำหรับอ่านและทำความเข้าใจเอกสาร และสื่อสารกับเพื่อนร่วมงาน
  • มีแนวคิดเชิงรุกและมีความร่วมมือ และมีความหลงใหลในการพัฒนาเกม
  • Design Principles: มีความคุ้นเคยกับแนวคิด flow, pacing, feedback loops, player motivation และ balancing
  • Documentation Tools: Google Docs, Microsoft Office Suite, Miro, Confluence
  • Verbal: สามารถแสดงความคิด ดีไซน์ และ feedback ในการประชุมทีมอย่างชัดเจน
  • Written: สามารถสร้างเอกสารดีไซน์ที่ชัดเจน กระชับ และครอบคลุม
  • Love Playing Games - ชอบเล่นเกม!

ความรับผิดชอบหลัก

  • ช่วยเหลือในการออกแบบ Game Features: ช่วยในการออกแบบและปรับสมดุลของ game features, systems, mechanics และ content
  • อาจรวมถึงการคิดไอเดียใหม่ๆ ปรับปรุงไอเดียที่มีอยู่ หรือค้นคว้าแนวทาง gameplay ที่แตกต่างกัน
  • สร้างและดูแลเอกสารดีไซน์โดยละเอียด รวมถึง game flows, system designs และ Game Design Documents (GDD)
  • เรียนรู้และรับ Feedback: พัฒนาทักษะที่สำคัญในการรับคำวิจารณ์เชิงสร้างสรรค์เกี่ยวกับดีไซน์ และแสดง feedback ต่อผู้อื่นอย่างเป็นประโยชน์และเป็นมืออาชีพ
  • สร้าง Portfolio: ได้รับประสบการณ์การทำงานที่จับต้องได้และผลงานที่สามารถนำไปใส่ใน professional portfolio เพื่อเพิ่มโอกาสในการทำงานในอนาคต
  • Networking: สร้างความสัมพันธ์กับผู้เชี่ยวชาญในอุตสาหกรรมที่สามารถให้คำแนะนำ คำปรึกษา และโอกาสในอนาคต

สิ่งที่จะได้เรียนรู้

  • ได้รับประสบการณ์จริงในกระบวนการพัฒนาเกม
  • เรียนรู้เทคนิคและวิธีการสร้างเกม
  • เข้าใจองค์กร, วงจรชีวิตของโปรเจค และวัฒนธรรมการทำงานแบบมืออาชีพ
  • ได้รับประสบการณ์ hands-on กับเครื่องมือและระบบการจัดการโปรเจค
  • พัฒนาทักษะการสื่อสารที่แข็งแกร่งในทีม การรายงานผล และเอกสารโปรเจค
  • สร้างรากฐานที่แข็งแกร่งในแนวปฏิบัติและพื้นฐานการจัดการโปรเจค
  • เติบโตผ่านความรับผิดชอบที่แท้จริง การทำงานเป็นทีม และงานโปรเจคที่มีการดูแล
