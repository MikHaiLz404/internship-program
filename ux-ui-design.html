เกี่ยวกับตำแหน่ง About the Role

ออกแบบอินเทอร์เฟซและประสบการณ์ผู้ใช้ที่ใช้งานง่ายและสวยงามสำหรับเกมของเรา ทำงานร่วมกับ Game Designers และ Programmers เพื่อให้แน่ใจว่า UI สอดคล้องกับระบบเกม Design user-friendly interfaces and experiences for our games. Collaborate with Game Designers and Programmers to ensure UI consistency with game systems.

บรรยากาศการทำงาน Work Environment

เราทำงานร่วมกับทีมต่างๆ เพื่อออกแบบ Wireframes และ Flow ที่ตอบโจทย์ผู้ใช้งานและรองรับทุกอุปกรณ์ พร้อมสร้าง Design System ที่แข็งแรงให้ทีม UI นำไปสานต่อ รวมถึงวิเคราะห์ Feedback ผู้เล่นเพื่อพัฒนาผลงานอย่างต่อเนื่อง เราขับเคลื่อนด้วยความอินในเกมและความเข้าใจผู้อื่น เพราะเราเชื่อว่า "ความเข้าอกเข้าใจ" คือหัวใจสำคัญของการสร้างประสบการณ์ที่ยอดเยี่ยม We collaborate across teams to design user-centric wireframes and responsive flows, establishing robust design systems for our UI partners. Our process extends to analyzing player feedback for continuous improvement. Driven by empathy and a passion for games, we believe understanding people is key to creating exceptional experiences.

คุณสมบัติ Qualifications

  • มีความเข้าใจหลักการ UX/UI เป็นอย่างดี Strong understanding of UX/UI principles
  • เชี่ยวชาญในการใช้เครื่องมือออกแบบเช่น Figma, Adobe XD หรือ Photoshop Proficiency in design tools like Figma, Adobe XD, or Photoshop
  • มีความสามารถในการสร้าง Wireframes, Prototypes และ Mockups Ability to create Wireframes, Prototypes, and Mockups
  • มีความสนใจในเกมและเข้าใจพฤติกรรมผู้เล่น Interest in games and understanding of player behavior

ความรับผิดชอบหลัก Key Responsibilities

  • ออกแบบ UI/UX สำหรับเมนูเกม, HUD และระบบอื่นๆ Design UI/UX for game menus, HUDs, and other systems
  • สร้าง Assets สำหรับ UI และนำไปใช้ใน Engine (ถ้าทำได้) Create UI assets and implement them in the engine (if possible)
  • ทดสอบและปรับปรุง UX ตาม Feedback Test and iterate UX based on feedback

สิ่งที่จะได้เรียนรู้ Learning Objectives

  • กระบวนการออกแบบ UI สำหรับเกมโดยเฉพาะ Game-specific UI design process
  • การทำงานร่วมกับทีมพัฒนาเกม Collaboration with game development teams
  • การนำงานออกแบบไปใช้จริงใน Game Engine Implementing designs in a Game Engine
