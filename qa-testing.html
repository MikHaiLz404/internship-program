เกี่ยวกับตำแหน่ง

QA Tester มีบทบาทสำคัญในการทดสอบเกมบนมือถือและ PC รวมถึง functional, performance และ regression testing เพื่อให้แน่ใจว่าเกมมีคุณภาพสูงสุดก่อนส่งมอบให้ผู้เล่น

คุณสมบัติ

  • Functional, Regression และ Performance Testing
  • ความเข้าใจพื้นฐานเกี่ยวกับ game design หรือ game development
  • ทักษะการสื่อสารที่ดีและมีประสิทธิภาพ
  • อ่านและเขียนภาษาอังกฤษในระดับที่จำเป็นสำหรับอ่านและทำความเข้าใจเอกสาร และสื่อสารกับเพื่อนร่วมงาน
  • มีแนวคิดเชิงรุกและมีความร่วมมือ และมีความหลงใหลในการพัฒนาเกม
  • Understanding of Agile/Scrum - ความเข้าใจพื้นฐาน
  • Basic experience with bug tracking tools and QA best practices
  • Basic experience with version control systems like Git or SVN
  • Game content creation experience - ประสบการณ์ในการสร้างคอนเทนต์เกม

ความรับผิดชอบหลัก

  • ทดสอบเกมอย่างครอบคลุมบนมือถือและ PC รวมถึง functional, performance และ regression testing
  • ออกแบบ test cases และดำเนินการทดสอบ
  • ระบุและรายงาน bugs และ issues ที่ส่งผลกระทบต่อ functionality ของเกม
  • ทำงานร่วมกับทีมพัฒนาเพื่อแก้ไขปัญหาและปรับปรุงคุณภาพเกม
  • ทดสอบเกมทั้งบน mobile devices และ computers
  • เรียนรู้และใช้เครื่องมือ bug tracking และ test documentation

สิ่งที่จะได้เรียนรู้

  • เรียนรู้กระบวนการทดสอบเกมในสภาพแวดล้อมการพัฒนาแบบมืออาชีพ
  • ระบุ วิเคราะห์ และรายงานข้อบกพร่อง
  • เข้าใจประเภทของการทดสอบ (functional, compatibility, regression, performance) และวิธีเลือกการทดสอบที่เหมาะสม
  • เรียนรู้การใช้เครื่องมือติดตามบั๊กและเอกสารการทดสอบ (test cases, test plans)
  • ได้รับประสบการณ์การทำงานกับทีมพัฒนาเกมที่หลากหลาย
  • เข้าใจมาตรฐานคุณภาพของอุตสาหกรรมเกม
