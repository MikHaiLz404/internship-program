เกี่ยวกับตำแหน่ง About the Role

พัฒนาและดูแลแอปพลิเคชันซอฟต์แวร์และเครื่องมือภายในเพื่อสนับสนุนกระบวนการพัฒนาเกม ทำงานร่วมกับทีมต่างๆ เพื่อปรับปรุงประสิทธิภาพการทำงาน Develop and maintain software applications and internal tools to support the game development process. Collaborate with various teams to improve workflow efficiency.

บรรยากาศการทำงาน Work Environment

บรรยากาศในทีมเปิดกว้างและส่งเสริมการพูดคุยเกี่ยวกับปัจจัยด้านการออกแบบ กิจกรรมประจำวันคือการค้นคว้าและสร้าง GDD (Game Design Document) The team environment is open-minded and encourages discussion about design factors. Typical daily activities are researching and creating a GDD (Game Design Document).

คุณสมบัติ Qualifications

  • เชี่ยวชาญในภาษาโปรแกรมสมัยใหม่ เช่น Python, JavaScript หรือ C# Proficiency in modern programming languages like Python, JavaScript, or C#
  • มีประสบการณ์ในการพัฒนา Web Application หรือ Backend Services Experience in developing Web Applications or Backend Services
  • เข้าใจเรื่อง Database และ API Design Understanding of Databases and API Design
  • คุ้นเคยกับ Cloud Services (AWS/GCP) จะพิจารณาเป็นพิเศษ Familiarity with Cloud Services (AWS/GCP) is a plus

ความรับผิดชอบหลัก Key Responsibilities

  • ออกแบบและสร้างเครื่องมือเพื่อช่วยให้ทีมพัฒนาเกมทำงานได้เร็วขึ้น Design and build tools to help the game development team work faster
  • ดูแลและปรับปรุงระบบ Backend ของเกม Maintain and improve game Backend systems
  • เขียน Automation Scripts เพื่อลดงานซ้ำซ้อน Write Automation Scripts to reduce repetitive tasks

สิ่งที่จะได้เรียนรู้ Learning Objectives

  • วงจรการพัฒนาซอฟต์แวร์ (SDLC) ในอุตสาหกรรมเกม Software Development Life Cycle (SDLC) in the game industry
  • การออกแบบระบบที่รองรับผู้ใช้งานจำนวนมาก (Scalability) Designing scalable systems
  • เทคโนโลยี Cloud และ DevOps Cloud and DevOps technologies
