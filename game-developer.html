เกี่ยวกับตำแหน่ง About the Role

พัฒนาระบบเกมและกลไกต่างๆ โดยใช้ Unity หรือ Unreal Engine ทำงานร่วมกับ Game Designers และ Artists เพื่อสร้างประสบการณ์การเล่นเกมที่ดีที่สุด Develop game mechanics and systems using Unity or Unreal Engine. Collaborate with Game Designers and Artists to create the best gameplay experience.

บรรยากาศการทำงาน Work Environment

เราทำงานในรูปแบบ Agile Sprint ที่มีเป้าหมายชัดเจน โดยร่วมมือกับทีม Design, UX/UI และ Technical Art เพื่อพัฒนาฟีเจอร์ต่างๆ สมาชิกทุกคนมีบทบาทสำคัญในงานที่ได้รับมอบหมายและได้รับการดูแลจากรุ่นพี่อย่างใกล้ชิด ผ่านกระบวนการทำงานที่เน้นการรีวิว ออกแบบ และลงมือทำจริง เพื่อให้มั่นใจว่าทุกคนได้สร้างสรรค์ผลงานที่มีคุณภาพร่วมกัน We utilize an Agile Sprint approach with clear goals, collaborating closely with Designers, UX/UI, and Technical Artists to develop features. Team members play a significant role in their assigned tasks with continuous mentorship from seniors. Our workflow involves a cycle of review, design, and implementation, ensuring that everyone’s input contributes to the final product.

  • มีความรู้ C# หรือ C++ เป็นอย่างดี Strong knowledge of C# or C++
  • มีประสบการณ์การใช้ Unity หรือ Unreal Engine Experience with Unity or Unreal Engine
  • เข้าใจหลักการ OOP และ Design Patterns Understanding of OOP principles and Design Patterns
  • มีทักษะการแก้ปัญหาและ Debugging ที่ดี Good problem-solving and debugging skills
  • สามารถทำงานร่วมกับผู้อื่นได้ดี Ability to work well with others

ความรับผิดชอบหลัก Key Responsibilities

  • เขียนโค้ดสำหรับฟีเจอร์เกมต่างๆ (Movement, Combat, UI, etc.) Implement gameplay features (Movement, Combat, UI, etc.)
  • แก้ไขบั๊กและปรับปรุงประสิทธิภาพของโค้ด Fix bugs and optimize code performance
  • ทำงานร่วมกับทีมอื่นเพื่อนำ Assets เข้าสู่เกม Collaborate with other teams to integrate assets into the game
  • เขียน Unit Test และทำ Documentation (ถ้าจำเป็น) Write Unit Tests and Documentation (if needed)
