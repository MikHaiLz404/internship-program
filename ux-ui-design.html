  • ระยะเวลา: 4-6 เดือน (ยืดหยุ่นตามภาคเรียน)

เกี่ยวกับตำแหน่ง

UX/UI Design Department ของเราเป็นส่วนหนึ่งของทีม Design ซึ่งประกอบด้วยทั้ง Game Designers และ UX/UI Designers

ภารกิจของเรา: สร้างประสบการณ์ที่ยอดเยี่ยมสำหรับผู้เล่นเกม เริ่มตั้งแต่การระดมความคิด features และเสนอไอเดียที่สร้างสรรค์ ไปจนถึงการออกแบบ wireframes และ flows ที่สอดคล้องกับความต้องการที่ Game Designers กำหนดไว้ เรายังเน้นการออกแบบ game assets และจัดเรียงทุกอย่างภายใน layouts ที่เข้ากันได้กับอุปกรณ์ต่างๆ

เราทำหน้าที่เป็นองค์ประกอบที่เชื่อมโยงความพยายามของทุกแผนกเข้าด้วยกัน เพื่อให้มั่นใจในความสวยงามและความกลมกลืนโดยรวมของเกม

คุณสมบัติ

  • Figma / Sketch / Adobe XD (preferred) - เครื่องมือออกแบบ UI/UX
  • Adobe Illustrator (Required) - สำหรับสร้าง assets
  • Adobe Photoshop (Basic level) - สำหรับแก้ไขภาพ
  • Design Principles: มีความคุ้นเคยกับแนวคิด flow, pacing, feedback loops, player motivation และ balancing
  • Documentation Tools: Google Docs, Microsoft Office Suite, Miro, Confluence
  • Verbal: สามารถแสดงไอเดีย ดีไซน์ และ feedback ในการประชุมทีมอย่างชัดเจน
  • Written: สร้างเอกสารดีไซน์ที่ชัดเจน กระชับ และครอบคลุม
  • Love Playing Games

ความรับผิดชอบหลัก

  • Main Tasks: รวบรวมความต้องการจาก Mentor สำหรับการออกแบบ feature
  • ออกแบบ low-fidelity wireframes (ขึ้นอยู่กับความต้องการของงาน)
  • ปรับแต่งและแก้ไขตาม feedback จาก Mentor เพื่อสร้าง high-fidelity wireframes
  • ออกแบบ game assets เพื่อรองรับการแสดงผลในจุดต่างๆ พร้อมรักษาคุณภาพความสวยงาม
  • เข้าร่วมรวบรวม feedback จากผู้ใช้ ไม่ว่าจะเป็น internal หรือ external
  • ทุกขั้นตอน คุณสามารถปรึกษากับสมาชิกในทีมที่เกี่ยวข้องได้ เนื่องจากนี่เป็นส่วนหนึ่งของการฝึกอบรมในการทำงานเป็น UX/UI Designer

สิ่งที่จะได้เรียนรู้

  • ทำความคุ้นเคยกับ Figma เพื่อสร้าง wireframes และสร้าง design components
  • เรียนรู้วิธีคิดแบบ UX Designer รวมถึงการทำ usability tests
  • เรียนรู้ความรู้พื้นฐานสำหรับการออกแบบ responsive layout/devices
  • ปรับแต่ง game assets ให้ตรงตามมาตรฐานอุตสาหกรรม
  • Documentation Best Practices: เรียนรู้การสร้างเอกสารดีไซน์ระดับมืออาชีพ (GDDs, feature specifications, flowcharts) ที่สื่อสารไอเดียไปยังทีมข้ามสายงานได้อย่างมีประสิทธิภาพ
  • Version Control Systems: เข้าใจและใช้เครื่องมืออย่าง Git สำหรับการพัฒนาร่วมกัน เรียนรู้วิธีจัดการการเปลี่ยนแปลงและแก้ไข conflicts
  • Receiving and Giving Feedback: พัฒนาทักษะที่สำคัญในการรับคำวิจารณ์เชิงสร้างสรรค์เกี่ยวกับดีไซน์ และแสดง feedback ต่อผู้อื่นอย่างเป็นประโยชน์และเป็นมืออาชีพ
  • Building a Portfolio: ได้รับประสบการณ์การทำงานที่จับต้องได้และผลงานที่สามารถนำไปใส่ใน professional portfolio เพื่อเพิ่มโอกาสในการทำงานในอนาคตอย่างมาก
  • Networking: สร้างความสัมพันธ์กับผู้เชี่ยวชาญในอุตสาหกรรมที่สามารถให้คำแนะนำ คำปรึกษา และโอกาสในอนาคต
