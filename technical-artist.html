Technical Artist Intern

Bridge Art and Technology in Game Development

ข้อมูลทั่วไป

  • จำนวนรับ: 1 ตำแหน่ง
  • ระยะเวลา: 4-6 เดือน (ยืดหยุ่นตามภาคเรียน)
  • สถานที่: Hybrid Work (สลับทำงานที่สำนักงานและที่บ้าน)
  • เวลาทำงาน: จันทร์-ศุกร์ 09:00-18:00 น.
  • โปรเจคปัจจุบัน: Regulus - The Advent, Father Son Holy Guns

เกี่ยวกับตำแหน่ง

Technical Artist เป็นสะพานเชื่อมระหว่างศิลปะและเทคโนโลยี ทำงานร่วมกับ Artists และ Programmers เพื่อให้แน่ใจว่า assets และ visual effects ทำงานได้อย่างมีประสิทธิภาพในเกม

นี่เป็นโอกาสที่ดีในการได้รับประสบการณ์ hands-on ในสตูดิโอเกมที่มีจังหวะเร็วและมีส่วนร่วมกับทีมพัฒนาแบบมืออาชีพ

คุณสมบัติ

  • Must have: Unity - มีประสบการณ์การใช้ Unity Engine
  • Nice to have: C# - ความรู้พื้นฐานด้านการเขียน C# scripts
  • Nice to have: PSD - ทักษะการใช้ Adobe Photoshop
  • Nice to have: AE (After Effects) - ทักษะการทำ VFX และ motion graphics
  • Nice to have: Adobe Designer
  • ความสามารถในการสื่อสารที่ดีและเต็มใจแบ่งปันไอเดียกับทีม
  • เต็มใจเรียนรู้และร่วมมือกับผู้อื่นในสภาพแวดล้อมแบบ agile
  • ความสนใจในการพัฒนาเกมหรือประสบการณ์ที่เกี่ยวข้อง (เช่น โปรเจคส่วนตัว, งานที่โรงเรียน)
  • ความเข้าใจพื้นฐานเกี่ยวกับ Unity Engine และ C#
  • ความคุ้นเคยกับ Git และแนวคิด version control
  • ทักษะการแก้ปัญหาที่ดีและมีทัศนคติเชิงรุก

ความรับผิดชอบหลัก

  • สร้าง game prefabs เช่น characters และ environments
  • ตั้งค่า UI Canvas ตามดีไซน์จาก Figma และปรับให้เหมาะสมกับ platforms ต่างๆ เช่น PC, Mobile และ Tablet
  • สื่อสารและประสานงานกับทีมอื่นๆ เพื่อปรับปรุงคุณภาพของงาน
  • ตั้งค่า Animation Trees เพื่อให้ตัวละครเคลื่อนไหวได้อย่างถูกต้อง
  • สร้าง shaders ที่เข้ากับ concept art
  • เขียน C# scripts เพื่อทำให้งานซ้ำๆ เป็นอัตโนมัติ

สิ่งที่จะได้เรียนรู้

  • ได้รับความเข้าใจเกี่ยวกับ game development pipeline จากการทำงานกับผลิตภัณฑ์จริง
  • เรียนรู้แนวปฏิบัติที่ดีที่สุดสำหรับการเขียน code ที่สะอาดและดูแลรักษาได้ใน Unity และ C#
  • ได้รับประสบการณ์การทำงานในสภาพแวดล้อมการพัฒนาแบบมืออาชีพ
  • ปรับปรุงทักษะ problem-solving และ collaboration ด้วยการทำงานร่วมกับ developers ที่มีประสบการณ์
  • ได้รับคำแนะนำจาก senior team members และความรู้ที่มีค่าเกี่ยวกับอุตสาหกรรมเกม

Software และ Tools

Game Engine: Unity (Required)

Programming: C#

Graphics: Adobe Photoshop, Adobe After Effects, Adobe Designer

3D Tools: Maya, Blender, 3ds Max (Basic)

Version Control: Git

Design: Figma

Shader: ShaderGraph, HLSL/GLSL (Basic)

Learning Objectives

  • ได้รับความเข้าใจเกี่ยวกับ game development pipeline จากการทำงานกับ real-world product
  • เรียนรู้แนวปฏิบัติที่ดีที่สุดสำหรับการเขียน code ที่สะอาด ดูแลรักษาได้ใน Unity และ C#
  • ได้รับประสบการณ์การทำงานในสภาพแวดล้อมการพัฒนาแบบมืออาชีพ
  • พัฒนาทักษะ problem-solving และ collaboration ด้วยการทำงานร่วมกับ developers ที่มีประสบการณ์
  • ได้รับคำแนะนำจาก senior team members และความรู้ที่มีค่าเกี่ยวกับอุตสาหกรรมเกม
